# 黑骑士自动化测试

`BlackKnightRules.Tests` 是一个**离线可执行**的测试工程，直接把唯一事实来源
`NinjaModCode/Monsters/BlackKnightRules.cs` 编译进测试程序集，因此不依赖 sts2 / Godot / BaseLib，
可在任意机器上独立运行。

## 运行

```powershell
dotnet run --project tests/BlackKnightRules.Tests -c Release
```

全部通过时退出码为 `0`，任一断言失败退出码为 `1`（便于接入 CI）。

## 覆盖范围（对应 todo 第十三节）

覆盖 16 个测试中与游戏运行时无关的**核心规则**（共 30 条断言）：

- T1 基础属性：最大/初始生命 500
- T2 状态机顺序：完整循环严格固定 + `NextState` 逐步推进
- T3 斜劈 25；T4/T5 横砍 34 + 未完全格挡才洗入伤口
- T6 竖劈 43 且默认不可格挡不治疗
- T7/T8/T9 打出诅咒后竖劈可格挡，按**实际生命伤害**治疗（部分格挡按实伤、完全格挡为 0）
- T10 怯懦：N 层影响接下来 N 张进入手牌的幽冥诅咒，每张消耗 1 层
- T11 暗鬼铠甲：N=3 → 黑骑士 +150 格挡、玩家 +3 层怯懦
- T12 真身：+5 力量、后续 横砍→横砍→竖劈+、三次后回到诅咒发放
- T13 多循环：连续两整圈无错位
- T14 首战覆盖：Debug 开关 / 幕序号 / 房间类型 / 一次性 的替换判定
- T15/T16 存档恢复用到的状态分类谓词（真身可见性、竖劈保护绑定）

> 涉及真实伤害结算、格挡、抽牌、动画节点清理、战斗存档的部分（需要游戏运行时），
> 通过开启 `BlackKnightConfig.DebugForceBlackKnightFirstEncounter` 进入第一幕第一场战斗实机验证。
