# 黑骑士自动化测试

`BlackKnightRules.Tests` 是一个**离线可执行**的测试工程，直接把唯一事实来源
`NinjaModCode/Monsters/BlackKnightRules.cs` 编译进测试程序集，因此不依赖 sts2 / Godot / BaseLib，
可在任意机器上独立运行。

## 运行

```powershell
dotnet run --project tests/BlackKnightRules.Tests -c Release
```

全部通过时退出码为 `0`，任一断言失败退出码为 `1`（便于接入 CI）。

## 覆盖范围（对应 todo 第十三节）

覆盖与游戏运行时无关的**核心规则**：

- T1 基础属性：最大/初始生命 500
- T2 状态机顺序：完整循环严格固定；运行时 `FollowUpStateId` 由唯一规则序列生成；发布用 `intentgraph.json` 的每一条边与初始状态也会被直接解析校验
- T3 斜劈 25；T4/T5 横砍 34 + 未完全格挡才洗入伤口
- 竖劈基础伤害 43；玩家回合结束时手牌有幽冥诅咒才对该玩家不可格挡
- 噬命诅印按**实际生命伤害**治疗；完全格挡为 0，每次独立攻击只消耗 1 层
- 幽冥侵蚀：作为黑暗骑士真身 Buff，分别处理每名玩家每回合第一张真正从抽牌堆进入手牌的幽冥诅咒
- 暗鬼铠甲：N=3 → 黑骑士 +150 格挡
- T12 真身：+5 力量与幽冥侵蚀；同回合完整重施“每名玩家 5 张幽冥诅咒 + 按成功数量获得噬命诅印”；后续 横砍→横砍→竖劈+，三次后回到诅咒发放
- T13 多循环：连续两整圈无错位
- T14 第三幕固定终战：只匹配 0-based 幕序号 2；标准/自定义模式均生效；普通模式使用 Boss 槽，高进阶双 Boss 使用第二 Boss 槽
- A10 旧档地图迁移：已有第二 Boss 遭遇但缺少地图节点时，补齐紧随第一 Boss 的节点
- 旧的首战调试覆盖判定仍保留离线回归，但发布配置已关闭
- 存档恢复用到的真身与招式状态分类谓词

> 涉及真实伤害结算、格挡、抽牌、动画节点清理、战斗存档的部分（需要游戏运行时），
> 现在通过第三幕最终 Boss 节点实机验证。普通难度应只有最终一战是黑骑士；
> 高进阶双 Boss 应保留原生第一只 Boss，并让黑骑士固定成为第二只 Boss。
